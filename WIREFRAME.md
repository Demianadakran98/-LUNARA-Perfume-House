# Lunara — Low Fidelity Wireframe

## 1. Home
- Header: logo / Home / Shop / FAQ / Contact / Wishlist / Cart
- Hero: headline / supporting copy / primary CTA / decorative fragrance visual
- Featured perfumes: 4 product cards
- Shop by occasion: Birthday / Wedding / Gift / Personal
- Reviews: 3 short review cards
- Footer: navigation + WhatsApp / phone / email / owner area

## 2. Product Listing
- Page title + discovery copy
- Search field
- Category select
- Sort select (featured / price ascending / price descending)
- Occasion chips
- Scent-note chips
- Min / max price fields + reset
- Responsive product grid

## 3. Product Details
- Large product image
- Product name / category / rating / price
- Size selector: only available bottle sizes
- Gift wrapping selector: yes/no where supported
- Availability
- Add to cart
- Wishlist
- Description / notes / ingredients

## 4. Cart
- Item image
- Product name
- Size / gift wrapping
- Quantity stepper
- Remove
- Subtotal + total
- Checkout CTA

## 5. Checkout
- Name / phone / delivery address / optional note
- Order summary
- CTA: review order & continue to WhatsApp

## 6. WhatsApp Review
- Customer information
- Products / quantities / prices
- Total
- Open WhatsApp with pre-filled message

## 7. Wishlist
- Saved product grid
- Remove / add to cart

## 8. FAQ / Contact
- FAQ accordions
- WhatsApp / phone / email
- Contact form

## 9. Owner area
- Products: add / edit / remove / availability / price & details
- Inquiries: view / remove
