# Lunara — Submission Ready

This is the frontend-only final submission for the current assignment stage.

## Included
- Responsive Lunara perfume store UI
- Product discovery, search, filters and sorting
- Product details and allowed variants: bottle size + gift wrapping
- Wishlist
- Cart and guest checkout
- Order review and WhatsApp handoff
- FAQ, reviews/ratings and contact options
- Owner product/inquiry management prototype
- Accessibility and responsive considerations
- Requirement mapping and QA checklist

## Intentionally not included yet
- Backend
- Database
- Automatic payment
- Automatic delivery management

Those can be added in the later backend phase.

## Run
Open `index.html` with VS Code Live Server.
